# SIEM Investigation Labs

This repository contains hands-on SIEM investigation labs performed in a controlled lab environment using log analysis, event correlation, and evidence-based reporting.

The goal of this repository is to document practical security investigations across multiple scenarios and data sources while following a structured SOC investigation methodology.

## Objectives

- Practice security event investigation workflows.
- Develop log analysis and threat hunting skills.
- Improve investigation and reporting techniques.
- Gain practical experience with SIEM technologies.
- Build a portfolio of documented SOC investigations.

## Current Investigations

### 1. Suspicious Process Investigation

Investigation focused on Windows process creation events, process lineage analysis, command-line review, and executable validation.

Each investigation follows a structured approach:

1. Investigation Scope
2. Scenario
3. Evidence Collection
4. Analysis
5. Verdict
6. Recommended Actions
