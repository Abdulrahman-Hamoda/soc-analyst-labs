# Baseline Investigations

This directory contains investigations of known legitimate processes and services.

## Purpose

The objective is to build familiarity with normal Windows behavior and create a reference point for future investigations.

## Contents

### Screenshots

Evidence collected during the investigation process.

### Report

Formal investigation reports documenting findings and conclusions.

## Expected Outcomes

- Understand normal process execution.
- Identify legitimate parent-child process relationships.
- Reduce false positives during investigations.
